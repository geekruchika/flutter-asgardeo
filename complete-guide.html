Complete Guide

A comprehensive guide to implementing authentication in your Flutter app with Asgardeo

⏱️ Estimated time: 30 minutes
1

Introduction

2 mins

Flutter is a popular cross-platform framework developed by Google for creating mobile, web, and desktop applications from a single codebase. It enables developers to build responsive interfaces using a rich set of pre-designed widgets and a reactive programming model.

Implementing login functionality in your Flutter app is essential for managing user access, personalizing user experiences, and securing the app. It enhances user experience, protects user data, boosts engagement, and helps ensure regulatory compliance.

Learning objectives

This guide will walk you through everything you need to know about securing Flutter apps, including implementing user login in your Flutter app, integrating it with an Identity Provider (IdP) to make the login process simple and secure, and general guidelines to protect your end users.

In this guide, you will:

  • Register an application in Asgardeo
  • Create a Flutter app
  • Install Asgardeo Flutter SDK
  • Add login and logout to your app
  • Display logged in user details
  • Secure routes in your app
  • Access protected APIs
  • Manage tokens in Flutter

Configure an Application in Asgardeo

2 mins

Register your Flutter application in the Asgardeo console.

Step 3.1: Register the Application

  1. Sign in to the Asgardeo Console
  2. Go to Applications → New Application
  3. Select Mobile Application
  4. Enter a name (e.g., "My Flutter App")
  5. Click Register

Step 3.2: Configure OAuth Settings

  1. Go to the Protocol tab
  2. Under Allowed grant types, select Authorization Code
  3. Under Authorized redirect URLs, add: myapp://callback
  4. Enable Public client
  5. Click Update
Note: Replace myapp with a unique URL scheme for your application.

Install and Configure Asgardeo SDK

3 mins

Step 5.1: Add Dependencies

Add to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  asgardeo_flutter: ^0.1.0
  uni_links: ^0.5.1
  flutter_web_auth_2: ^4.0.3
  http: ^1.2.2

Install the dependencies:

flutter pub get

Step 5.2: Configure Deep Links (Android)

Edit android/app/src/main/AndroidManifest.xml:

<activity android:name=".MainActivity">
  <intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="myapp" android:host="callback" />
  </intent-filter>
</activity>

Step 5.3: Configure Deep Links (iOS)

Edit ios/Runner/Info.plist:

<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>myapp</string>
    </array>
  </dict>
</array>
Important: Make sure the URL scheme (myapp) matches what you configured in Asgardeo console.

Add Login and Logout

3 mins

Initialize the SDK in lib/main.dart:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

void main() {
  runApp(
    AsgardeoProvider(
      config: AsgardeoConfig(
        baseUrl: 'https://api.asgardeo.io/t/<your-org>',
        clientId: '<your-client-id>',
        afterSignInUrl: 'myapp://callback',
        afterSignOutUrl: 'myapp://callback',
        scopes: ['openid', 'profile', 'email'],
      ),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Asgardeo Demo',
      home: HomePage(),
    );
  }
}

Add authentication UI:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('My App'),
        actions: [
          SignedIn(
            child: UserButton(),
          ),
        ],
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            SignedIn(
              child: Column(
                children: [
                  const Text('You are signed in!'),
                  const SizedBox(height: 16),
                  SignOutButton(),
                ],
              ),
            ),
            SignedOut(
              child: SignInButton(),
            ),
          ],
        ),
      ),
    );
  }
}
Tip: The SignedIn and SignedOut widgets automatically show/hide content based on authentication state.

Display User Details

2 mins

Get and display user profile information:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    final auth = AsgardeoProvider.of(context);

    return Scaffold(
      appBar: AppBar(title: const Text('Profile')),
      body: FutureBuilder<UserProfile>(
        future: auth.getUserProfile(),
        builder: (context, snapshot) {
          if (!snapshot.hasData) {
            return const Center(child: CircularProgressIndicator());
          }

          final user = snapshot.data!;
          return ListView(
            padding: const EdgeInsets.all(16),
            children: [
              ListTile(
                title: const Text('Username'),
                subtitle: Text(user.username ?? 'N/A'),
              ),
              ListTile(
                title: const Text('Email'),
                subtitle: Text(user.email ?? 'N/A'),
              ),
              ListTile(
                title: const Text('Name'),
                subtitle: Text(user.name ?? 'N/A'),
              ),
            ],
          );
        },
      ),
    );
  }
}

Securing Routes

2 mins

Protect routes by requiring authentication:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class ProtectedRoute extends StatelessWidget {
  final Widget child;
  
  const ProtectedRoute({super.key, required this.child});

  @override
  Widget build(BuildContext context) {
    return SignedIn(
      fallback: Scaffold(
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              const Icon(Icons.lock, size: 48),
              const SizedBox(height: 16),
              const Text('Please sign in to access this page'),
              const SizedBox(height: 24),
              SignInButton(),
            ],
          ),
        ),
      ),
      child: child,
    );
  }
}

// Usage
class ProtectedPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return ProtectedRoute(
      child: Scaffold(
        appBar: AppBar(title: const Text('Protected Page')),
        body: const Center(
          child: Text('This is a protected page'),
        ),
      ),
    );
  }
}

Accessing Protected APIs

3 mins

Make authenticated API calls with access tokens:

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'dart:convert';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

Future<Map<String, dynamic>> fetchProtectedData(BuildContext context) async {
  final auth = AsgardeoProvider.of(context);
  final token = await auth.getAccessToken();

  final response = await http.get(
    Uri.parse('https://api.example.com/data'),
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
  );

  if (response.statusCode == 200) {
    return json.decode(response.body);
  } else if (response.statusCode == 401) {
    // Token expired, sign out
    await auth.signOut();
    throw Exception('Authentication expired');
  } else {
    throw Exception('Failed to load data');
  }
}
Best Practice: Always handle 401 responses by signing out the user, as this indicates the token has expired or is invalid.

Manage Tokens in Flutter

2 mins

Understanding Token Lifecycle

  • Access Token: Short-lived (typically 1 hour), used for API calls
  • Refresh Token: Long-lived token used to obtain new access tokens
  • ID Token: Contains user information and claims

Token Best Practices

// Always get fresh access token before API calls
final token = await auth.getAccessToken();

// The SDK automatically handles token refresh
// No need to manually manage refresh tokens
Security Tips:
  • Always call getAccessToken() before making API requests
  • Never cache tokens manually in your app
  • Use flutter_secure_storage for sensitive data in production
  • Handle 401 responses by signing out the user
  • Don't store tokens in SharedPreferences
