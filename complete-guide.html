Introduction

2 mins

Flutter is a popular cross-platform framework developed by Google for creating mobile, web, and desktop applications from a single codebase. It enables developers to build responsive interfaces using a rich set of pre-designed widgets and a reactive programming model.

Implementing login functionality in your Flutter app is essential for managing user access, personalizing user experiences, and securing the app. It enhances user experience, protects user data, boosts engagement, and helps ensure regulatory compliance.

Learning objectives

This guide will walk you through everything you need to know about securing Flutter apps, including implementing user login in your Flutter app, integrating it with an Identity Provider (IdP) to make the login process simple and secure, and general guidelines to protect your end users.

In this guide, you will:

  • Register an application in Asgardeo
  • Create a Flutter app
  • Install Asgardeo Flutter SDK
  • Add login and logout to your app
  • Display logged in user details
  • Secure routes in your app
  • Access protected APIs
  • Manage tokens in Flutter

Configure an Application in Asgardeo

2 mins

Register your Flutter application in the Asgardeo console.

Step 3.1: Register the Application

  1. Sign in to the Asgardeo Console
  2. Go to Applications → New Application
  3. Select Mobile Application
  4. Enter a name (e.g., "My Flutter App")
  5. Click Register

Step 3.2: Configure OAuth Settings

  1. Go to the Protocol tab
  2. Under Allowed grant types, select Authorization Code
  3. Under Authorized redirect URLs, add: myapp://callback
  4. Enable Public client
  5. Click Update
Note: Replace myapp with a unique URL scheme for your application.

Install and Configure Asgardeo SDK

3 mins

Step 5.1: Add Dependencies

Add to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  asgardeo_flutter: ^0.1.0
  uni_links: ^0.5.1
  flutter_web_auth_2: ^4.0.3
  http: ^1.2.2

Install the dependencies:

flutter pub get
Optional - For Enhanced Security:

For production apps, add these packages for secure token storage and biometric authentication (covered in Step 10): 

dependencies:
  flutter_secure_storage: ^9.0.0  # Native secure storage
  local_auth: ^2.1.8               # Biometric authentication

Step 5.2: Configure Deep Links (Android)

Edit android/app/src/main/AndroidManifest.xml:

<activity android:name=".MainActivity">
  <intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="myapp" android:host="callback" />
  </intent-filter>
</activity>

Step 5.3: Configure Deep Links (iOS)

Edit ios/Runner/Info.plist:

<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>myapp</string>
    </array>
  </dict>
</array>
Important: Make sure the URL scheme (myapp) matches what you configured in Asgardeo console.

Display Logged-In User Details

4 mins

At this point, we've successfully implemented login and logout capabilities using the Asgardeo Flutter SDK. The next step is to explore how to access and display logged-in user details within the app.

The Flutter SDK provides widgets and methods to display user information in a declarative way:

  • User Widget: Provides a declarative way to display user profile information
  • UserButton Widget: A dropdown menu with built-in user information and sign-out functionality
  • AsgardeoProvider.of(context): Programmatic access to user profile data via getUserProfile()

Method 1: Using the User Widget

The User widget from the SDK provides a simple way to display user information declaratively:

Method 3: Accessing User Profile Programmatically

Use AsgardeoProvider.of(context).getUserProfile() to fetch and display detailed user information: 

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    final auth = AsgardeoProvider.of(context);

    return Scaffold(
      appBar: AppBar(
        title: const Text('My Profile'),
        actions: [
          SignedIn(child: UserButton()),
        ],
      ),
      body: FutureBuilder<UserProfile>(
        future: auth.getUserProfile(),
        builder: (context, snapshot) {
          // Show loading indicator
          if (snapshot.connectionState == ConnectionState.waiting) {
            return const Center(
              child: CircularProgressIndicator(),
            );
          }

          // Handle errors
          if (snapshot.hasError) {
            return Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  const Icon(Icons.error_outline, size: 48, color: Colors.red),
                  const SizedBox(height: 16),
                  Text('Error: ${snapshot.error}'),
                  const SizedBox(height: 16),
                  ElevatedButton(
                    onPressed: () => Navigator.pop(context),
                    child: const Text('Go Back'),
                  ),
                ],
              ),
            );
          }

          // Display user profile
          final user = snapshot.data!;
          return ListView(
            padding: const EdgeInsets.all(16),
            children: [
              // User Avatar
              Center(
                child: CircleAvatar(
                  radius: 50,
                  backgroundColor: Colors.blue,
                  child: Text(
                    user.name?.substring(0, 1).toUpperCase() ?? 
                    user.username?.substring(0, 1).toUpperCase() ?? 
                    'U',
                    style: const TextStyle(
                      fontSize: 36,
                      color: Colors.white,
                    ),
                  ),
                ),
              ),
              const SizedBox(height: 24),

              // Profile Information Card
              Card(
                child: Column(
                  children: [
                    ListTile(
                      leading: const Icon(Icons.person),
                      title: const Text('Username'),
                      subtitle: Text(user.username ?? 'N/A'),
                    ),
                    const Divider(),
                    ListTile(
                      leading: const Icon(Icons.badge),
                      title: const Text('Full Name'),
                      subtitle: Text(user.name ?? 'N/A'),
                    ),
                    const Divider(),
                    ListTile(
                      leading: const Icon(Icons.email),
                      title: const Text('Email'),
                      subtitle: Text(user.email ?? 'N/A'),
                    ),
                    const Divider(),
                    ListTile(
                      leading: const Icon(Icons.phone),
                      title: const Text('Phone'),
                      subtitle: Text(user.phoneNumber ?? 'N/A'),
                    ),
                    const Divider(),
                    ListTile(
                      leading: const Icon(Icons.location_on),
                      title: const Text('Country'),
                      subtitle: Text(user.country ?? 'N/A'),
                    ),
                  ],
                ),
              ),
            ],
          );
        },
      ),
    );
  }
}

Creating an Editable Profile Page

Build a profile page where users can view and update their information: 

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class EditableProfilePage extends StatefulWidget {
  const EditableProfilePage({super.key});

  @override
  State<EditableProfilePage> createState() => _EditableProfilePageState();
}

class _EditableProfilePageState extends State<EditableProfilePage> {
  final _formKey = GlobalKey<FormState>();
  final _nameController = TextEditingController();
  final _emailController = TextEditingController();
  final _phoneController = TextEditingController();
  
  bool _isEditing = false;
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _loadUserProfile();
  }

  Future<void> _loadUserProfile() async {
    final auth = AsgardeoProvider.of(context);
    try {
      final user = await auth.getUserProfile();
      setState(() {
        _nameController.text = user.name ?? '';
        _emailController.text = user.email ?? '';
        _phoneController.text = user.phoneNumber ?? '';
        _isLoading = false;
      });
    } catch (e) {
      setState(() => _isLoading = false);
    }
  }

  Future<void> _saveProfile() async {
    if (!_formKey.currentState!.validate()) return;

    setState(() => _isLoading = true);

    try {
      // Call your API to update user profile
      // final auth = AsgardeoProvider.of(context);
      // await auth.updateUserProfile({
      //   'name': _nameController.text,
      //   'email': _emailController.text,
      //   'phone': _phoneController.text,
      // });

      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Profile updated successfully'),
            backgroundColor: Colors.green,
          ),
        );
        setState(() {
          _isEditing = false;
          _isLoading = false;
        });
      }
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text('Failed to update profile: $e'),
            backgroundColor: Colors.red,
          ),
        );
        setState(() => _isLoading = false);
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('My Profile'),
        actions: [
          if (!_isEditing)
            IconButton(
              icon: const Icon(Icons.edit),
              onPressed: () => setState(() => _isEditing = true),
              tooltip: 'Edit Profile',
            )
          else
            IconButton(
              icon: const Icon(Icons.close),
              onPressed: () {
                setState(() => _isEditing = false);
                _loadUserProfile();
              },
              tooltip: 'Cancel',
            ),
        ],
      ),
      body: _isLoading
          ? const Center(child: CircularProgressIndicator())
          : SingleChildScrollView(
              padding: const EdgeInsets.all(16),
              child: Form(
                key: _formKey,
                child: Column(
                  children: [
                    // Avatar
                    CircleAvatar(
                      radius: 50,
                      backgroundColor: Colors.blue,
                      child: Text(
                        _nameController.text.isNotEmpty
                            ? _nameController.text[0].toUpperCase()
                            : 'U',
                        style: const TextStyle(
                          fontSize: 36,
                          color: Colors.white,
                        ),
                      ),
                    ),
                    const SizedBox(height: 24),

                    // Name field
                    TextFormField(
                      controller: _nameController,
                      decoration: InputDecoration(
                        labelText: 'Full Name',
                        prefixIcon: const Icon(Icons.person),
                        border: const OutlineInputBorder(),
                        enabled: _isEditing,
                      ),
                      validator: (value) {
                        if (value == null || value.isEmpty) {
                          return 'Please enter your name';
                        }
                        return null;
                      },
                    ),
                    const SizedBox(height: 16),

                    // Email field
                    TextFormField(
                      controller: _emailController,
                      decoration: InputDecoration(
                        labelText: 'Email',
                        prefixIcon: const Icon(Icons.email),
                        border: const OutlineInputBorder(),
                        enabled: _isEditing,
                      ),
                      validator: (value) {
                        if (value == null || value.isEmpty) {
                          return 'Please enter your email';
                        }
                        if (!value.contains('@')) {
                          return 'Please enter a valid email';
                        }
                        return null;
                      },
                    ),
                    const SizedBox(height: 16),

                    // Phone field
                    TextFormField(
                      controller: _phoneController,
                      decoration: InputDecoration(
                        labelText: 'Phone Number',
                        prefixIcon: const Icon(Icons.phone),
                        border: const OutlineInputBorder(),
                        enabled: _isEditing,
                      ),
                    ),
                    const SizedBox(height: 24),

                    // Save button
                    if (_isEditing)
                      ElevatedButton.icon(
                        onPressed: _saveProfile,
                        icon: const Icon(Icons.save),
                        label: const Text('Save Changes'),
                        style: ElevatedButton.styleFrom(
                          minimumSize: const Size(double.infinity, 50),
                        ),
                      ),
                  ],
                ),
              ),
            ),
    );
  }

  @override
  void dispose() {
    _nameController.dispose();
    _emailController.dispose();
    _phoneController.dispose();
    super.dispose();
  }
}

Available User Profile Attributes

The UserProfile object contains the following attributes: 

class UserProfile {
  final String? username;      // User's unique username
  final String? name;           // Full name
  final String? givenName;      // First name
  final String? familyName;     // Last name
  final String? email;          // Email address
  final bool? emailVerified;    // Email verification status
  final String? phoneNumber;    // Phone number
  final String? country;        // Country
  final String? locale;         // Preferred locale
  final String? sub;            // Subject identifier (unique ID)
  final List<String>? roles;   // User roles/groups
  final Map<String, dynamic>? customAttributes; // Custom claims
}
Best Practices:
  • Use FutureBuilder to handle async user profile fetching
  • Always check for null values when displaying user attributes
  • Show loading indicators while fetching user data
  • Handle errors gracefully with user-friendly messages
  • Cache user profile data locally to reduce API calls (use StatefulWidget or state management)
  • Use UserButton widget for quick access to user actions
  • Validate user input before updating profile information

Securing Routes Within the App

4 mins

Securing routes in Flutter apps is essential to protect sensitive content and ensure only authenticated users can access specific screens. This guide covers conditional rendering, route guards, navigation patterns, and deep link protection for mobile apps.

Conditional Rendering with SignedIn/SignedOut

The Asgardeo Flutter SDK provides built-in widgets for conditional rendering based on authentication state. These widgets automatically show or hide content depending on whether a user is signed in.

Protected Route Wrapper

Create a reusable ProtectedRoute widget that wraps any screen and enforces authentication: 

import 'package:flutter/material.dart';

class ProtectedRoute extends StatelessWidget {

Route Guards with Navigator 2.0

For more advanced routing control, implement route guards using Flutter's Navigator 2.0 pattern: 

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class AuthRouterDelegate extends RouterDelegate<RouteInformation>
    with ChangeNotifier, PopNavigatorRouterDelegateMixin<RouteInformation> {
  
  @override
  final GlobalKey<NavigatorState> navigatorKey;
  
  final AsgardeoAuth auth;
  String? _currentPath;

  AuthRouterDelegate(this.auth) : navigatorKey = GlobalKey<NavigatorState>() {
    // Listen to auth state changes
    auth.addListener(_handleAuthStateChange);
  }

  void _handleAuthStateChange() {
    notifyListeners();
  }

  @override
  Widget build(BuildContext context) {
    return Navigator(
      key: navigatorKey,
      pages: [
        // Public routes
        MaterialPage(
          key: const ValueKey('home'),
          child: HomePage(),
        ),
        
        // Protected routes - only show if authenticated
        if (auth.isAuthenticated && _currentPath == '/profile')
          MaterialPage(
            key: const ValueKey('profile'),
            child: ProfilePage(),
          ),
        
        if (auth.isAuthenticated && _currentPath == '/settings')
          MaterialPage(
            key: const ValueKey('settings'),
            child: SettingsPage(),
          ),
        
        // Redirect to login if not authenticated
        if (!auth.isAuthenticated && _isProtectedRoute(_currentPath))
          MaterialPage(
            key: const ValueKey('login'),
            child: LoginPage(),
          ),
      ],
      onPopPage: (route, result) {
        if (!route.didPop(result)) {
          return false;
        }
        _currentPath = '/';
        notifyListeners();
        return true;
      },
    );
  }

  bool _isProtectedRoute(String? path) {
    const protectedRoutes = ['/profile', '/settings', '/dashboard'];
    return protectedRoutes.contains(path);
  }

  @override
  Future<void> setNewRoutePath(RouteInformation configuration) async {
    _currentPath = configuration.location;
    notifyListeners();
  }

  @override
  void dispose() {
    auth.removeListener(_handleAuthStateChange);
    super.dispose();
  }
}

    BuildContext context,

      case settings:
        return MaterialPageRoute(builder: (_) => SettingsPage());

      default:
        return MaterialPageRoute(
          builder: (_) => Scaffold(

    }
  }

    _sub = uriLinkStream.listen((Uri? uri) async {
      if (uri != null) {

    }, onError: (err) {
      debugPrint('Deep link error: $err');
    });

  Future<void> _handleDeepLink(Uri uri) async {
    final auth = AsgardeoProvider.of(context);
    final path = uri.path;
    
    // Handle OAuth callback
    if (path.contains('callback')) {
      await auth.handleRedirect(uri);
      return;
    }

    // Check if deep link route requires authentication
    final protectedRoutes = ['/profile', '/settings', '/dashboard'];
    final requiresAuth = protectedRoutes.any((route) => path.contains(route));

    if (requiresAuth) {
      // Check authentication state
      if (await auth.isAuthenticated) {
        // Navigate to the protected route
        if (context.mounted) {
          Navigator.of(context).pushNamed(path);
        }
      } else {
        // Store intended destination and redirect to login
        await _storeIntendedRoute(path);
        if (context.mounted) {
          Navigator.of(context).pushReplacementNamed('/login');
          ScaffoldMessenger.of(context).showSnackBar(
            const SnackBar(
              content: Text('Please sign in to access this page'),
            ),
          );
        }
      }
    } else {
      // Navigate to public route
      if (context.mounted) {
        Navigator.of(context).pushNamed(path);
      }
    }
  }

    // After successful login, redirect to this route
  }

    _sub?.cancel();
  }

Role-Based Access Control (RBAC)

Implement role-based routing for fine-grained access control:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class RoleBasedRoute extends StatelessWidget {
  final Widget child;
  final List<String> requiredRoles;
  final String? deniedMessage;

  const RoleBasedRoute({
    super.key,
    required this.child,
    required this.requiredRoles,
    this.deniedMessage,
  });

  @override
  Widget build(BuildContext context) {
    final auth = AsgardeoProvider.of(context);

    return FutureBuilder<UserProfile>(
      future: auth.getUserProfile(),
      builder: (context, snapshot) {
        if (!snapshot.hasData) {
          return const Scaffold(
            body: Center(child: CircularProgressIndicator()),
          );
        }

        final user = snapshot.data!;
        final userRoles = user.roles ?? [];
        final hasAccess = requiredRoles.any((role) => userRoles.contains(role));

        if (!hasAccess) {
          return Scaffold(
            appBar: AppBar(title: const Text('Access Denied')),
            body: Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  const Icon(Icons.block, size: 64, color: Colors.red),
                  const SizedBox(height: 16),
                  Text(
                    deniedMessage ?? 'You do not have permission to access this page',
                    textAlign: TextAlign.center,
                  ),
                  const SizedBox(height: 24),
                  ElevatedButton(
                    onPressed: () => Navigator.of(context).pop(),
                    child: const Text('Go Back'),
                  ),
                ],
              ),
            ),
          );
        }

        return child;
      },
    );
  }
}

Best Practices for Mobile Route Security

Security Best Practices:
  • ✅ Always validate authentication state on route navigation, not just UI rendering
  • ✅ Implement route guards for all protected screens, including deep links
  • ✅ Handle authentication state changes with automatic navigation
  • ✅ Use fallback screens with clear messaging for unauthenticated users
  • ✅ Clear navigation stack on sign out to prevent back-button access
  • ✅ Store intended routes and redirect after successful login
  • ✅ Validate tokens before showing sensitive content, even on protected routes
  • ❌ Don't rely solely on UI hiding - always enforce security at the route level
  • ❌ Don't cache sensitive screens in the navigation stack after logout
  • ❌ Don't forget deep link security - they bypass normal navigation

import 'package:flutter/material.dart';

  }
}

Manage Tokens in Flutter Apps

5 mins

Proper token management is critical for maintaining security and user experience in mobile applications. This guide covers token validation, secure storage, lifecycle management, and best practices specific to Flutter mobile apps.

Token Validation

A key principle of security tokens is that the receiver must first validate the token. This involves checking the authenticity of the token issuer, ensuring the token meets validity criteria such as expiration time, and confirming that the receiver is authorized to use the token.

The Asgardeo Flutter SDK handles token validation automatically as part of its authentication and session management process. When a user signs in, the SDK acquires:

  • Access Token: By default an opaque token, used for API authorization (typically 1 hour validity)
  • ID Token: A JWT containing user information and claims
  • Refresh Token: Long-lived token for obtaining new access tokens

The SDK automatically validates tokens by checking:

  • Signature Validation: Verifies the JWT's signature using the public key from Asgardeo's JWKS endpoint
  • Expiration Check: Validates the exp claim to ensure tokens haven't expired
  • Issuer Validation: Confirms the iss claim matches your Asgardeo organization
  • Audience Validation: Ensures the aud claim matches your client ID

Token Persistence with Secure Storage

On mobile devices, token security is paramount. Unlike web apps that use browser storage, mobile apps must use native secure storage mechanisms to protect sensitive authentication data.

Installing Flutter Secure Storage

Add flutter_secure_storage to your pubspec.yaml: 

dependencies:
  flutter_secure_storage: ^9.0.0

Platform-Specific Secure Storage

flutter_secure_storage uses native platform APIs to securely store tokens:

  • iOS: Uses the Keychain Services - Apple's secure storage system that encrypts data and requires device authentication for access
  • Android: Uses the Android Keystore system, which stores cryptographic keys in a hardware-backed container (on supported devices) or software keystore

iOS Configuration

For iOS, add KeychainAccess to your ios/Runner/Info.plist: 

<key>KeychainAccessGroups</key>
<array>
  <string>$(AppIdentifierPrefix)com.yourcompany.yourapp</string>
</array>

Android Configuration

    }

Implementing Secure Token Storage

Create a service to manage secure token storage:

import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class SecureTokenStorage {
  final _storage = const FlutterSecureStorage(
    aOptions: AndroidOptions(
      encryptedSharedPreferences: true,
      // Use hardware-backed encryption on supported devices
      resetOnError: true,
    ),
    iOptions: IOSOptions(
      accessibility: KeychainAccessibility.first_unlock,
      // Require biometric authentication for access
      accountName: 'com.yourcompany.yourapp',
    ),
  );

  // Store access token
  Future<void> saveAccessToken(String token) async {
    await _storage.write(
      key: 'access_token',
      value: token,
    );
  }

  // Retrieve access token
  Future<String?> getAccessToken() async {
    return await _storage.read(key: 'access_token');
  }

  // Store refresh token
  Future<void> saveRefreshToken(String token) async {
    await _storage.write(
      key: 'refresh_token',
      value: token,
    );
  }

  // Retrieve refresh token
  Future<String?> getRefreshToken() async {
    return await _storage.read(key: 'refresh_token');
  }

  // Store ID token
  Future<void> saveIdToken(String token) async {
    await _storage.write(
      key: 'id_token',
      value: token,
    );
  }

  // Clear all tokens on logout
  Future<void> clearAllTokens() async {
    await _storage.delete(key: 'access_token');
    await _storage.delete(key: 'refresh_token');
    await _storage.delete(key: 'id_token');
  }

  // Check if tokens exist
  Future<bool> hasTokens() async {
    final accessToken = await _storage.read(key: 'access_token');
    return accessToken != null;
  }
}

Token Lifecycle Management

Proper token lifecycle management ensures users stay authenticated and your app handles token expiration gracefully.

Automatic Token Refresh

The Asgardeo SDK automatically handles token refresh. When the access token is about to expire, the SDK uses the refresh token to obtain a new access token without user intervention: 

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class ApiService {
  final BuildContext context;
  
  ApiService(this.context);

  Future<String> getValidAccessToken() async {
    final auth = AsgardeoProvider.of(context);
    
    // SDK automatically refreshes if token is expired
    final token = await auth.getAccessToken();
    
    if (token == null) {
      throw Exception('No valid access token available');
    }
    
    return token;
  }

  Future<void> makeAuthenticatedRequest() async {
    try {
      final token = await getValidAccessToken();
      
      // Use token in API call
      final response = await http.get(
        Uri.parse('https://api.example.com/data'),
        headers: {
          'Authorization': 'Bearer $token',
        },
      );
      
      // Handle response
    } catch (e) {
      // Handle token refresh failure
      print('Authentication error: $e');
    }
  }
}

Handling Token Expiration

Always handle 401 responses which indicate expired or invalid tokens: 

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

Future<void> makeApiCall(BuildContext context) async {
  final auth = AsgardeoProvider.of(context);
  final token = await auth.getAccessToken();

  final response = await http.get(
    Uri.parse('https://api.example.com/protected'),
    headers: {'Authorization': 'Bearer $token'},
  );

  if (response.statusCode == 401) {
    // Token expired and couldn't be refreshed
    // Clear local session and redirect to login
    await auth.signOut();

      Navigator.of(context).pushReplacementNamed('/login');
      
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Session expired. Please sign in again.'),
        ),
      );
    }
  } else if (response.statusCode == 200) {
    // Process successful response
  }
}

Initiate Logout

When a user logs out, the SDK ensures both the local session and the session on Asgardeo are terminated:

  1. Local Session Termination: The SDK clears locally stored tokens and credentials
  2. Secure Storage Cleanup: All tokens are removed from iOS Keychain / Android Keystore
  3. Remote Sign Out: User is signed out from Asgardeo globally (important for SSO scenarios)
  4. Redirect: User is redirected to the configured post-logout URL 
import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class LogoutButton extends StatelessWidget {
  const LogoutButton({super.key});

  Future<void> _handleLogout(BuildContext context) async {
    final auth = AsgardeoProvider.of(context);
    
    try {
      // Show loading indicator
      showDialog(
        context: context,
        barrierDismissible: false,
        builder: (context) => const Center(
          child: CircularProgressIndicator(),
        ),
      );

      // Sign out (clears tokens and signs out from Asgardeo)
      await auth.signOut();
      
      // Clear secure storage
      final secureStorage = SecureTokenStorage();
      await secureStorage.clearAllTokens();

      if (context.mounted) {
        Navigator.of(context).pop(); // Close loading dialog
        Navigator.of(context).pushReplacementNamed('/login');
      }
    } catch (e) {
      if (context.mounted) {
        Navigator.of(context).pop();
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('Logout failed: $e')),
        );
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () => _handleLogout(context),
      child: const Text('Sign Out'),
    );
  }
}

Security Best Practices for Mobile Apps

Critical Security Guidelines:
  • ✅ DO: Always use flutter_secure_storage for tokens
  • ✅ DO: Call getAccessToken() before every API request
  • ✅ DO: Handle 401 responses by signing out the user
  • ✅ DO: Enable biometric authentication for sensitive operations
  • ✅ DO: Clear all tokens on logout
  • ❌ DON'T: Store tokens in SharedPreferences or plain text
  • ❌ DON'T: Cache tokens in memory longer than necessary
  • ❌ DON'T: Log tokens in debug output
  • ❌ DON'T: Share tokens between apps
  • ❌ DON'T: Transmit tokens over insecure connections
