Quick Start Guide

Get up and running with Asgardeo authentication in your Flutter app in under 10 minutes.

Prerequisites

  • ✓
    Flutter 3.22 or higher

    Ensure you have Flutter installed. Run flutter --version to check.

  • ✓
    An Asgardeo account

    Sign up for free at asgardeo.io

  • ✓
    Basic Flutter knowledge

    Familiarity with Flutter widgets and state management

Step 1: Installation

Add the Asgardeo Flutter SDK and required dependencies to your pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  asgardeo_flutter: ^0.1.0
  uni_links: ^0.5.1
  flutter_web_auth_2: ^4.0.3

Then install the dependencies:

flutter pub get

Step 2: Configure Asgardeo Application

2.1 Create an Application

  1. Log in to your Asgardeo Console
  2. Navigate to Applications → New Application
  3. Select Mobile Application (or SPA for web)
  4. Enter a name (e.g., "My Flutter App")

2.2 Configure OAuth Settings

In your application settings, configure the following:

  • Authorized redirect URLs: myapp://callback
  • Allowed grant types: Authorization Code
  • Public client: Enable (mobile apps don't use client secrets)
Note: Replace myapp with your app's custom URL scheme. Make sure it's unique and matches your bundle identifier pattern.

2.3 Save Your Credentials

Copy the following values from your Asgardeo application:

  • Client ID: Your application's unique identifier
  • Base URL: Your organization's API URL (e.g., https://api.asgardeo.io/t/yourorg)

Step 3: Configure Deep Links

Deep links allow your app to receive the authentication callback from Asgardeo.

3.1 Android Configuration

Edit android/app/src/main/AndroidManifest.xml and add an intent filter inside your <activity> tag:

<activity
    android:name=".MainActivity"
    android:launchMode="singleTop">
    
    <!-- Existing intent filters... -->
    
    <!-- Add this intent filter for deep linking -->
    <intent-filter android:autoVerify="true">
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.DEFAULT" />
        <category android:name="android.intent.category.BROWSABLE" />
        <data
            android:scheme="myapp"
            android:host="callback" />
    </intent-filter>
</activity>

3.2 iOS Configuration

Edit ios/Runner/Info.plist and add URL scheme configuration:

<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>myapp</string>
        </array>
    </dict>
</array>
Important: Make sure the scheme value (myapp) matches what you configured in Asgardeo and is unique to your application.

Step 4: Initialize the SDK

Wrap your app with AsgardeoProvider in your main.dart:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

void main() {
  runApp(
    AsgardeoProvider(
      config: AsgardeoConfig(
        baseUrl: 'https://api.asgardeo.io/t/<your-org>',
        clientId: '<your-client-id>',
        afterSignInUrl: 'myapp://callback',
        afterSignOutUrl: 'myapp://callback',
        scopes: ['openid', 'profile', 'email'],
      ),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Asgardeo Flutter Demo',
      theme: ThemeData(
        useMaterial3: true,
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
      ),
      home: const HomePage(),
    );
  }
}
Configuration Options:
  • baseUrl: Your Asgardeo organization's API base URL
  • clientId: Your application's client ID from Asgardeo console
  • afterSignInUrl: Redirect URL after successful sign-in
  • afterSignOutUrl: Redirect URL after sign-out
  • scopes: OAuth scopes to request (default: openid, profile, email)

Step 5: Add Authentication UI

Use the pre-built widgets to add sign-in and sign-out functionality:

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Asgardeo Demo'),
        actions: [
          SignedIn(
            child: Padding(
              padding: const EdgeInsets.only(right: 8),
              child: UserButton(),
            ),
          ),
        ],
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            SignedIn(
              fallback: const Text('Please sign in to continue'),
              child: Column(
                children: [
                  const Text(
                    'Welcome! You are signed in.',
                    style: TextStyle(fontSize: 18),
                  ),
                  const SizedBox(height: 20),
                  SignOutButton(),
                ],
              ),
            ),
            SignedOut(
              child: SignInButton(),
            ),
          ],
        ),
      ),
    );
  }
}

Step 6: Handle Authentication Redirects

Set up a listener to handle incoming deep links after authentication:

import 'dart:async';
import 'package:flutter/material.dart';
import 'package:uni_links/uni_links.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

class HomePage extends StatefulWidget {
  const HomePage({super.key});
  
  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  StreamSubscription? _sub;

  @override
  void initState() {
    super.initState();
    _initDeepLinks();
  }

  Future<void> _initDeepLinks() async {
    _sub = uriLinkStream.listen((Uri? uri) async {
      if (!mounted || uri == null) return;
      
      // Pass the callback URI to the SDK
      await AsgardeoProvider.of(context).handleRedirect(uri);
    }, onError: (err) {
      debugPrint('Deep link error: $err');
    });
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    // Your UI code here
    return Scaffold(
      // ... rest of your UI
    );
  }
}
How it works: When users complete authentication in the browser, Asgardeo redirects back to your app using the custom URL scheme. The SDK intercepts this redirect, exchanges the authorization code for tokens, and updates the authentication state.

Step 7: Run Your App

You're all set! Run your app:

# For iOS
flutter run -d ios

# For Android
flutter run -d android

# For Web
flutter run -d chrome
🎉 Congratulations! You've successfully integrated Asgardeo authentication into your Flutter app. Users can now sign in securely using industry-standard OIDC.

Troubleshooting

Deep links not working?

  • Verify the URL scheme matches between your app config, Asgardeo console, and platform configurations
  • On iOS, make sure you've added the URL scheme to Info.plist
  • On Android, verify the intent filter is inside the correct activity

Authentication flow not completing?

  • Check that your redirect URL in Asgardeo matches exactly (including the scheme)
  • Ensure you're calling handleRedirect() in the deep link listener
  • Check the console logs for any error messages
