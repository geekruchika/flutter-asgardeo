Introduction

2 mins

iOS is Apple's mobile operating system for iPhone and iPad. Swift is a modern, powerful programming language that provides safe and expressive syntax for building iOS applications. SwiftUI is Apple's declarative framework for building user interfaces across all Apple platforms.

Implementing login functionality in your iOS app is essential for managing user access, personalizing user experiences, and securing the app. It enhances user experience, protects user data, boosts engagement, and helps ensure regulatory compliance.

Learning objectives

This guide will walk you through everything you need to know about securing iOS apps, including implementing user login in your iOS app, integrating it with an Identity Provider (IdP) to make the login process simple and secure, and general guidelines to protect your end users.

In this guide, you will:

  • Register an application in Asgardeo
  • Create an iOS app with Xcode
  • Install Asgardeo iOS SDK
  • Add login and logout to your app
  • Display logged in user details
  • Secure views in your app
  • Access protected APIs
  • Manage tokens securely with iOS Keychain

Configure an Application in Asgardeo

2 mins

Register your iOS application in the Asgardeo console.

Step 3.1: Register the Application

  1. Sign in to the Asgardeo Console
  2. Go to Applications → New Application
  3. Select Mobile Application
  4. Enter a name (e.g., "My iOS App")
  5. Click Register

Step 3.2: Configure OAuth Settings

  1. Go to the Protocol tab
  2. Under Allowed grant types, select Authorization Code
  3. Under Authorized redirect URLs, add: com.yourcompany.myapp://callback
  4. Enable Public client
  5. Click Update
Note: Replace com.yourcompany.myapp with your actual bundle identifier. This will be used as your custom URL scheme.

Create an iOS App with Xcode

2 mins

Create a new iOS application project:

  1. Open Xcode
  2. Select Create a new Xcode project
  3. Choose iOS → App template
  4. Configure your project:
    • Product Name: MyApp
    • Team: Select your team (or add Apple ID)
    • Organization Identifier: com.yourcompany
    • Bundle Identifier: com.yourcompany.myapp
    • Interface: SwiftUI
    • Language: Swift
  5. Click Next and choose a location to save your project

Test that your app runs by selecting a simulator and pressing Cmd + R or clicking the Run button.

Install and Configure Asgardeo iOS SDK

3 mins

Step 5.1: Add SDK via Swift Package Manager

Install the Asgardeo iOS SDK using SPM:

  1. In Xcode, select your project in the Project Navigator
  2. Select your app target
  3. Go to Package Dependencies tab
  4. Click the + button
  5. Enter repository URL: https://github.com/asgardeo/asgardeo-ios-sdk
  6. Click Add Package

Step 5.2: Configure Info.plist for URL Scheme

Add your custom URL scheme for OAuth callback:

  1. Open Info.plist in your project
  2. Right-click and select Add Row
  3. Add URL types (CFBundleURLTypes) as an Array
  4. Add a Dictionary item with:
    • URL Schemes (CFBundleURLSchemes): Array with your bundle ID 
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLName</key>
        <string>$(PRODUCT_BUNDLE_IDENTIFIER)</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>com.yourcompany.myapp</string>
        </array>
    </dict>
</array>
Important: Ensure the URL scheme matches exactly what you configured in Asgardeo console.

Add Login and Logout

3 mins

Initialize the SDK in your App.swift file:

import SwiftUI
import AsgardeoAuth

@main
struct MyApp: App {
    @StateObject private var auth = AsgardeoAuth.shared
    
    init() {
        // Configure Asgardeo SDK
        AsgardeoAuth.shared.configure(
            config: AsgardeoConfig(
                issuer: "https://api.asgardeo.io/t/<your-org>/oauth2/token",
                clientId: "<your-client-id>",
                redirectUri: "com.yourcompany.myapp://callback",
                scopes: ["openid", "profile", "email"],
                discoveryEndpoint: "https://api.asgardeo.io/t/<your-org>/oauth2/token/.well-known/openid-configuration"
            )
        )
    }
    
    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(auth)
                .onOpenURL { url in
                    // Handle OAuth callback
                    AsgardeoAuth.shared.handleCallback(url: url)
                }
        }
    }
}

Protected View Modifier

Create a reusable view modifier for protected views:

import SwiftUI
import AsgardeoAuth

struct AuthRequiredModifier: ViewModifier {
    @EnvironmentObject var auth: AsgardeoAuth
    let fallbackView: AnyView
    let message: String
    
    init(
        message: String = "Please sign in to access this page",
        fallback: some View = DefaultLoginPrompt()
    ) {
        self.message = message
        self.fallbackView = AnyView(fallback)
    }
    
    func body(content: Content) -> some View {
        if auth.isAuthenticated {
            content
        } else {
            fallbackView
        }
    }
}

extension View {
    func requiresAuth(
        message: String = "Please sign in to access this page"
    ) -> some View {
        modifier(AuthRequiredModifier(message: message))

Navigation Guard with NavigationStack (iOS 16+)

Implement navigation guards for modern iOS apps:

import SwiftUI
import AsgardeoAuth

enum AppRoute: Hashable {
    case home
    case profile
    case settings
    case dashboard
    case adminPanel
}

struct AppNavigationView: View {
    @EnvironmentObject var auth: AsgardeoAuth
    @State private var path = NavigationPath()
    @State private var selectedTab = 0
    
    var body: some View {
        NavigationStack(path: $path) {
            TabView(selection: $selectedTab) {
                HomeView()
                    .tabItem {
                        Label("Home", systemImage: "house")
                    }
                    .tag(0)
                
                NavigationLink(value: AppRoute.profile) {
                    Label("Profile", systemImage: "person")
                }
                .tabItem {
                    Label("Profile", systemImage: "person")
                }
                .tag(1)
            }
            .navigationDestination(for: AppRoute.self) { route in
                routeView(for: route)
            }
        }
    }
    
    @ViewBuilder
    private func routeView(for route: AppRoute) -> some View {
        switch route {
        case .home:
            HomeView()
        case .profile:
            if auth.isAuthenticated {
                ProfileView()
            } else {
                LoginRequiredView(intendedRoute: route)
            }
        case .settings:
            if auth.isAuthenticated {
                SettingsView()
            } else {
                LoginRequiredView(intendedRoute: route)
            }
        case .dashboard:
            if auth.isAuthenticated {
                DashboardView()
            } else {
                LoginRequiredView(intendedRoute: route)
            }
        case .adminPanel:
            if hasAdminRole {
                AdminPanelView()
            } else {
                AccessDeniedView()
            }
        }
    }
    
    private var hasAdminRole: Bool {
        guard auth.isAuthenticated,
              let roles = auth.user?.roles else {
            return false
        }
        return roles.contains("admin") || roles.contains("super_admin")
    }
}

Role-Based Access Control

Implement fine-grained role-based view protection:

import SwiftUI
import AsgardeoAuth

struct RoleProtectedView: View {
    @EnvironmentObject var auth: AsgardeoAuth
    let requiredRoles: [String]
    let content: Content
    let deniedView: DeniedView
    
    init(
        requiredRoles: [String],
        @ViewBuilder content: () -> Content,
        @ViewBuilder deniedView: () -> DeniedView = { DefaultAccessDeniedView() }
    ) {
        self.requiredRoles = requiredRoles
        self.content = content()
        self.deniedView = deniedView()
    }
    
    var body: some View {
        Group {
            if hasRequiredRole {
                content
            } else {
                deniedView
            }
        }
    }
    
    private var hasRequiredRole: Bool {
        guard auth.isAuthenticated,
              let userRoles = auth.user?.roles else {
            return false
        }
        return requiredRoles.contains(where: { userRoles.contains($0) })
    }
}

Deep Link Handling with Authentication

Protect deep links by checking authentication:

import SwiftUI
import AsgardeoAuth

@main
struct MyApp: App {
    @StateObject private var auth = AsgardeoAuth.shared
    @State private var pendingDeepLink: URL?
    
    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(auth)
                .onOpenURL { url in
                    handleDeepLink(url)
                }
        }
    }
    
    private func handleDeepLink(_ url: URL) {
        // Handle OAuth callback
        if url.absoluteString.contains("callback") {
            AsgardeoAuth.shared.handleCallback(url: url)
            
            // Navigate to pending deep link if exists
            if let pending = pendingDeepLink {
                navigateToDeepLink(pending)
                pendingDeepLink = nil
            }
            return
        }
        
        // Handle app deep links
        let protectedPaths = ["/profile", "/settings", "/dashboard", "/admin"]
        let isProtected = protectedPaths.contains(where: { url.path.contains($0) })
        
        if isProtected && !auth.isAuthenticated {
            // Store deep link and trigger sign in
            pendingDeepLink = url
            Task {
                try? await auth.signIn()
            }
        } else {
            navigateToDeepLink(url)
        }
    }
    
    private func navigateToDeepLink(_ url: URL) {
        // Navigate to the appropriate view based on URL
        // Implementation depends on your navigation structure
    }
}

State-Based Navigation

Auto-navigate based on authentication state changes:

import SwiftUI
import Combine
import AsgardeoAuth

class NavigationManager: ObservableObject {
    @Published var currentView: AppView = .landing
    private var cancellables = Set<AnyCancellable>()
    
    enum AppView {
        case landing
        case main
        case onboarding
    }
    
    init() {
        AsgardeoAuth.shared.$isAuthenticated
            .sink { [weak self] isAuthenticated in
                self?.handleAuthStateChange(isAuthenticated)
            }
            .store(in: &cancellables)
    }
    
    private func handleAuthStateChange(_ isAuthenticated: Bool) {
        if isAuthenticated {
            // Check if user needs onboarding
            if needsOnboarding() {
                currentView = .onboarding
            } else {
                currentView = .main
            }
        } else {
            currentView = .landing
        }
    }
    
    private func needsOnboarding() -> Bool {
        // Check if user has completed onboarding
        return UserDefaults.standard.bool(forKey: "hasCompletedOnboarding") == false
    }
}

struct RootView: View {
    @StateObject private var navigationManager = NavigationManager()
    @EnvironmentObject var auth: AsgardeoAuth
    
    var body: some View {
        Group {
            switch navigationManager.currentView {
            case .landing:
                LandingView()
            case .onboarding:
                OnboardingView()
            case .main:
                MainTabView()
            }
        }
        .animation(.easeInOut, value: navigationManager.currentView)
    }
}
Security Best Practices:
  • ✅ Always validate authentication state before showing protected content
  • ✅ Use environment objects to share auth state across views
  • ✅ Clear navigation stack and cached data on logout
  • ✅ Validate user roles on both client and server
  • ✅ Store intended destination when redirecting to login
  • ❌ Don't rely solely on UI hiding for security
  • ❌ Don't cache sensitive view states in memory
  • ❌ Don't forget to protect deep link entry points
💡 Pro Tip: For production apps, combine view-level security with server-side validation. Never trust client-side navigation alone - always validate authentication and authorization on your backend API.

Accessing Protected APIs

3 mins

Make authenticated API calls using access tokens from the Asgardeo SDK. This section covers URLSession integration, error handling, and SwiftUI integration patterns.

Basic API Service with Access Tokens

import Foundation
import AsgardeoAuth

class APIService {
    static let shared = APIService()
    private let baseURL = "https://api.example.com"
    
    enum HTTPMethod: String {
        case get = "GET"
        case post = "POST"
        case put = "PUT"
        case delete = "DELETE"
    }
    
    // GET request with authentication
    func fetchProtectedData(
        endpoint: String,
        responseType: T.Type
    ) async throws -> T {
        guard let token = AsgardeoAuth.shared.accessToken else {
            throw APIError.unauthorized
        }
        
        guard let url = URL(string: "\(baseURL)\(endpoint)") else {
            throw APIError.invalidURL
        }
        
        var request = URLRequest(url: url)
        request.httpMethod = HTTPMethod.get.rawValue
        request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.timeoutInterval = 30
        
        let (data, response) = try await URLSession.shared.data(for: request)
        
        guard let httpResponse = response as? HTTPURLResponse else {
            throw APIError.invalidResponse
        }
        
        switch httpResponse.statusCode {
        case 200...299:
            let decoder = JSONDecoder()
            decoder.keyDecodingStrategy = .convertFromSnakeCase
            return try decoder.decode(T.self, from: data)
            
        case 401:
            // Token expired - sign out user
            try? await AsgardeoAuth.shared.signOut()
            throw APIError.unauthorized
            
        case 403:
            throw APIError.forbidden
            
        case 404:
            throw APIError.notFound
            
        case 500...599:
            throw APIError.serverError(httpResponse.statusCode)
            
        default:
            throw APIError.httpError(httpResponse.statusCode)
        }
    }
    
    // POST request with body
    func postData(
        endpoint: String,
        body: T,
        responseType: R.Type
    ) async throws -> R {
        guard let token = AsgardeoAuth.shared.accessToken else {
            throw APIError.unauthorized
        }
        
        guard let url = URL(string: "\(baseURL)\(endpoint)") else {
            throw APIError.invalidURL
        }
        
        var request = URLRequest(url: url)
        request.httpMethod = HTTPMethod.post.rawValue
        request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        
        let encoder = JSONEncoder()
        encoder.keyEncodingStrategy = .convertToSnakeCase
        request.httpBody = try encoder.encode(body)
        
        let (data, response) = try await URLSession.shared.data(for: request)
        
        guard let httpResponse = response as? HTTPURLResponse,
              200...299 ~= httpResponse.statusCode else {
            throw APIError.httpError((response as? HTTPURLResponse)?.statusCode ?? 0)
        }
        
        let decoder = JSONDecoder()
        decoder.keyDecodingStrategy = .convertFromSnakeCase
        return try decoder.decode(R.self, from: data)
    }
}

enum APIError: LocalizedError {
    case unauthorized
    case forbidden
    case notFound
    case invalidURL
    case invalidResponse
    case httpError(Int)
    case serverError(Int)
    case decodingError
    
    var errorDescription: String? {
        switch self {
        case .unauthorized:
            return "Session expired. Please sign in again."
        case .forbidden:
            return "You don't have permission to access this resource."
        case .notFound:
            return "The requested resource was not found."
        case .invalidURL:
            return "Invalid URL."
        case .invalidResponse:
            return "Invalid server response."
        case .httpError(let code):
            return "HTTP Error: \(code)"
        case .serverError(let code):
            return "Server Error: \(code)"
        case .decodingError:
            return "Failed to parse server response."
        }
    }

Handling Token Refresh Automatically

import Foundation
import AsgardeoAuth

extension APIService {
    // Wrapper that handles token refresh automatically
    func makeAuthenticatedRequest(
        endpoint: String,
        method: HTTPMethod = .get,
        body: Data? = nil,
        responseType: T.Type
    ) async throws -> T {
        // First attempt with current token
        do {
            return try await performRequest(
                endpoint: endpoint,
                method: method,
                body: body,
                responseType: responseType
            )
        } catch APIError.unauthorized {
            // Token might be expired, try to refresh
            do {
                try await AsgardeoAuth.shared.refreshToken()
                
                // Retry with new token
                return try await performRequest(
                    endpoint: endpoint,
                    method: method,
                    body: body,
                    responseType: responseType
                )
            } catch {
                // Refresh failed, sign out user
                try? await AsgardeoAuth.shared.signOut()
                throw APIError.unauthorized
            }
        }
    }
    
    private func performRequest(
        endpoint: String,
        method: HTTPMethod,
        body: Data?,
        responseType: T.Type
    ) async throws -> T {
        guard let token = AsgardeoAuth.shared.accessToken else {
            throw APIError.unauthorized
        }
        
        guard let url = URL(string: "\(baseURL)\(endpoint)") else {
            throw APIError.invalidURL
        }
        
        var request = URLRequest(url: url)
        request.httpMethod = method.rawValue
        request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.httpBody = body
        
        let (data, response) = try await URLSession.shared.data(for: request)
        
        guard let httpResponse = response as? HTTPURLResponse else {
            throw APIError.invalidResponse
        }
        
        guard 200...299 ~= httpResponse.statusCode else {
            if httpResponse.statusCode == 401 {
                throw APIError.unauthorized
            }
            throw APIError.httpError(httpResponse.statusCode)
        }
        
        return try JSONDecoder().decode(T.self, from: data)
    }
}

Manage Tokens in iOS Apps

4 mins

Proper token management is critical for maintaining security in iOS applications. The Asgardeo iOS SDK automatically manages tokens and stores them securely using Apple's Keychain Services with hardware-backed encryption.

Token Validation

The SDK automatically validates tokens by checking signature, expiration, issuer, and audience claims. When you sign in, the SDK acquires:

  • Access Token: Short-lived (typically 1 hour), used for API authorization
  • ID Token: JWT containing user information and claims
  • Refresh Token: Long-lived token for obtaining new access tokens

The SDK validates tokens by checking:

  • Signature Validation: Verifies JWT signature using public key from Asgardeo's JWKS endpoint
  • Expiration Check: Validates the exp claim
  • Issuer Validation: Confirms the iss claim matches your organization
  • Audience Validation: Ensures aud matches your client ID

iOS Keychain Secure Storage

The Asgardeo SDK uses Apple's Keychain Services to securely store tokens. On devices with Secure Enclave (iPhone 5s and later), tokens are protected by hardware-backed encryption that cannot be extracted even if the device is compromised.

Token Security Best Practices

Critical Security Guidelines:
  • ✅ DO: Let the SDK manage token storage in Keychain automatically
  • ✅ DO: Use Face ID/Touch ID for sensitive operations
  • ✅ DO: Set kSecAttrSynchronizable to false (no iCloud sync)
  • ✅ DO: Handle 401 responses by signing out the user
  • ✅ DO: Clear all tokens and cached data on logout
  • ✅ DO: Use kSecAttrAccessibleAfterFirstUnlock for security
  • ❌ DON'T: Store tokens in UserDefaults or property lists
  • ❌ DON'T: Log tokens in debug output or analytics
  • ❌ DON'T: Cache tokens in memory longer than necessary
  • ❌ DON'T: Sync tokens to iCloud Keychain
  • ❌ DON'T: Share tokens between apps (even same developer)

import UIKit

class LoginViewController: UIViewController {

            self,
            selector: #selector(authStateChanged),
            name: .authStateDidChange,
            object: nil
        )
    }
    
    @objc private func authStateChanged() {
        DispatchQueue.main.async {
            self.updateUIForAuthState()
        }
    }
    
    private func updateUIForAuthState() {
        if auth.isAuthenticated {
            statusLabel.text = "Signed in as \(auth.user?.name ?? "User")"
            signInButton.setTitle("Sign Out", for: .normal)
        } else {
            statusLabel.text = "Not signed in"
            signInButton.setTitle("Sign In", for: .normal)
        }
    }
    
    @IBAction func signInButtonTapped(_ sender: UIButton) {
        if auth.isAuthenticated {
            signOut()
        } else {
            signIn()
        }
    }
    
    private func signIn() {
        Task {
            do {
                try await auth.signIn()
                await MainActor.run {
                    // Navigate to main app
                    let mainVC = MainTabBarController()
                    mainVC.modalPresentationStyle = .fullScreen
                    present(mainVC, animated: true)
                }
            } catch {
                await MainActor.run {
                    showError(error.localizedDescription)
                }
            }
        }
    }
    
    private func signOut() {
        Task {
            do {
                try await auth.signOut()
            } catch {
                await MainActor.run {
                    showError(error.localizedDescription)
                }
            }
        }
    }
    
    private func showError(_ message: String) {
        let alert = UIAlertController(
            title: "Error",
            message: message,
            preferredStyle: .alert
        )
        alert.addAction(UIAlertAction(title: "OK", style: .default))
        present(alert, animated: true)
