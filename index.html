Quick Example

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

void main() {
  runApp(
    AsgardeoProvider(
      config: AsgardeoConfig(
        baseUrl: 'https://api.asgardeo.io/t/<your-org>',
        clientId: '<your-client-id>',
        afterSignInUrl: 'myapp://callback',
        afterSignOutUrl: 'myapp://callback',
        scopes: ['openid', 'profile', 'email'],
      ),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              SignedIn(
                child: Column(
                  children: [
                    Text('Welcome! You are signed in.'),
                    SignOutButton(),
                  ],
                ),
              ),
              SignedOut(
                child: SignInButton(),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Flutter Quickstart

Get up and running with Asgardeo authentication in your Flutter app in under 10 minutes.

Welcome to the Flutter Quickstart guide! In this document, you will learn to build a Flutter app, add user sign-in and display user profile information using Asgardeo.

What You Will Learn

  • Create new Flutter app using recommended tools
  • Install asgardeo_flutter package
  • Add user sign-in and sign-out
  • Display user profile information

Prerequisites

Before you start, ensure you have the following:

  • About 10 minutes
  • Asgardeo account
  • Install Flutter 3.22+ on your system
  • A favorite text editor or IDE

Step 1: Configure Asgardeo Application

1.1 Create an Application

  1. Log in to your Asgardeo Console
  2. Navigate to Applications → New Application
  3. Select Mobile Application
  4. Enter a name (e.g., "My Flutter App")

1.2 Configure OAuth Settings

In your application settings, configure:

  • Authorized redirect URLs: myapp://callback
  • Allowed grant types: Authorization Code
  • Public client: Enable (mobile apps don't use client secrets)
Note: Replace myapp with your app's custom URL scheme. Make sure it's unique and matches your bundle identifier pattern.

Step 2: Installation

Add dependencies to your pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  asgardeo_flutter: ^0.1.0
  uni_links: ^0.5.1
  flutter_web_auth_2: ^4.0.3

Then install:

flutter pub get

Step 3: Configure Deep Links

3.1 Android Configuration

Edit android/app/src/main/AndroidManifest.xml:

<activity android:name=".MainActivity">
  <intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="myapp" android:host="callback" />
  </intent-filter>
</activity>

3.2 iOS Configuration

Edit ios/Runner/Info.plist:

<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>myapp</string>
    </array>
  </dict>
</array>

Step 6: Handle Authentication Redirects

import 'dart:async';
import 'package:uni_links/uni_links.dart';

class HomePage extends StatefulWidget {
  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  StreamSubscription? _sub;

  @override
  void initState() {
    super.initState();
    _sub = uriLinkStream.listen((Uri? uri) async {
      if (uri != null && mounted) {
        await AsgardeoProvider.of(context).handleRedirect(uri);
      }
    });
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    // Your UI here
  }
}

Complete Guide

A comprehensive guide to implementing authentication in your Flutter app

Architecture & Approach

The Asgardeo Flutter SDK uses OpenID Connect (OIDC) Authorization Code flow with PKCE:

Authentication Flow:
  1. User initiates sign-in from your Flutter app
  2. SDK opens system browser with Asgardeo authorization URL
  3. User authenticates with Asgardeo
  4. Asgardeo redirects back to your app via deep link
  5. SDK exchanges authorization code for access token
  6. User is now authenticated

Provider Pattern

The SDK uses Flutter's Provider pattern:

AsgardeoProvider
  └─ AsgardeoAuth (ChangeNotifier)
      ├─ isSignedIn
      ├─ isLoading
      └─ methods (signIn, signOut, etc.)

Making Authenticated API Calls

import 'package:http/http.dart' as http;

Future<void> fetchData() async {
  final auth = AsgardeoProvider.of(context);
  final token = await auth.getAccessToken();

  final response = await http.get(
    Uri.parse('https://api.example.com/data'),
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
  );

  if (response.statusCode == 200) {
    // Process response
  }
}

Best Practices

  • Secure Storage: Use flutter_secure_storage for tokens in production
  • Deep Links: Always set up deep link listeners properly
  • Protected Routes: Wrap sensitive screens with SignedIn component
  • Loading States: Show loading indicators during auth operations
  • Testing: Test on real devices, not just simulators

Display User Profile

class ProfilePage extends StatelessWidget {

Making API Calls

import 'package:http/http.dart' as http;
import 'dart:convert';

class ApiService {
  final BuildContext context;

  ApiService(this.context);

  Future<Map<String, dynamic>> fetchUserData() async {
    final auth = AsgardeoProvider.of(context);
    final token = await auth.getAccessToken();

    final response = await http.get(
      Uri.parse('https://api.example.com/user/me'),
      headers: {
        'Authorization': 'Bearer $token',
        'Content-Type': 'application/json',
      },
    );

    if (response.statusCode == 200) {
      return json.decode(response.body);
    } else if (response.statusCode == 401) {
      await auth.signOut();
      throw Exception('Authentication expired');
    } else {
      throw Exception('Failed to load data');
    }
  }
}

Error Handling

import 'dart:async';
import 'dart:io';

Future<void> handleSignIn(BuildContext context) async {
  try {
    final auth = AsgardeoProvider.of(context);
    await auth.signIn();
  } on TimeoutException {
    _showError(context, 'Request timed out. Please try again.');
  } on SocketException {
    _showError(context, 'No internet connection.');
  } catch (e) {
    _showError(context, 'Sign in failed: $e');
  }
}

void _showError(BuildContext context, String message) {
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(
      content: Text(message),
      backgroundColor: Colors.red,
    ),
  );
}

Organization Switching

class OrgSwitcherPage extends StatefulWidget {
  @override
  State<OrgSwitcherPage> createState() => _OrgSwitcherPageState();
}

class _OrgSwitcherPageState extends State<OrgSwitcherPage> {
  Future<void> _switchOrganization(Organization org) async {
    final auth = AsgardeoProvider.of(context);
    
    showDialog(
      context: context,
      barrierDismissible: false,
      builder: (context) => const Center(
        child: CircularProgressIndicator(),
      ),
    );

    try {
      await auth.switchOrganization(org);
      Navigator.pop(context);
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Switched to ${org.name}'),
          backgroundColor: Colors.green,
        ),
      );
    } catch (e) {
      Navigator.pop(context);
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Failed to switch: $e'),
          backgroundColor: Colors.red,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    final auth = AsgardeoProvider.of(context);

    return FutureBuilder<List<Organization>>(
      future: auth.getMyOrganizations(),
      builder: (context, snapshot) {
        if (!snapshot.hasData) {
          return const CircularProgressIndicator();
        }

        return ListView.builder(
          itemCount: snapshot.data!.length,
          itemBuilder: (context, index) {
            final org = snapshot.data![index];
            final isCurrent = auth.currentOrganization?.id == org.id;

            return ListTile(
              title: Text(org.name ?? org.id),
              trailing: isCurrent
                  ? const Chip(label: Text('Current'))
                  : TextButton(
                      onPressed: () => _switchOrganization(org),
                      child: const Text('Switch'),
                    ),
            );
          },
        );
      },
    );
  }
}
