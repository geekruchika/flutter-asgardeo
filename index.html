Integrate secure authentication into your Flutter applications with ease

Features

🔐

Secure Authentication

Implement OpenID Connect (OIDC) authentication with Authorization Code + PKCE flow for maximum security.

🎨

Pre-built Widgets

Use ready-to-go components like SignInButton, SignedIn, SignedOut, and UserButton to speed up development.

🏢

Organization Switching

Seamlessly switch between organizations with built-in support for multi-tenancy.

📱

Cross-Platform

Works on iOS, Android, and Web with platform-specific optimizations.

🔄

SSO Support

Single Sign-On using ASWebAuthenticationSession (iOS) and Custom Tabs (Android).

⚡

Developer Friendly

Simple API with Flutter's reactive programming model using Provider pattern.

Quick Example

import 'package:flutter/material.dart';
import 'package:asgardeo_flutter/asgardeo_flutter.dart';

void main() {
  runApp(
    AsgardeoProvider(
      config: AsgardeoConfig(
        baseUrl: 'https://api.asgardeo.io/t/<your-org>',
        clientId: '<your-client-id>',
        afterSignInUrl: 'myapp://callback',
        afterSignOutUrl: 'myapp://callback',
        scopes: ['openid', 'profile', 'email'],
      ),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              SignedIn(
                child: Column(
                  children: [
                    Text('Welcome! You are signed in.'),
                    SignOutButton(),
                  ],
                ),
              ),
              SignedOut(
                child: SignInButton(),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Prerequisites

  • ✓
    Asgardeo Account

    Create a free account at asgardeo.io

  • ✓
    Flutter 3.22+

    Install the latest Flutter SDK with Dart 3+

  • ✓
    Asgardeo Application

    Register your application in the Asgardeo console (Mobile/SPA type)

Installation

Add the SDK to your pubspec.yaml:

dependencies:
  asgardeo_flutter: ^0.1.0
  uni_links: ^0.5.1
  flutter_web_auth_2: ^4.0.3

Then run:

flutter pub get

Why Browser-Based Auth?

Security & Standards: The Asgardeo Flutter SDK uses the industry-standard OpenID Connect (OIDC) Authorization Code flow with PKCE, which is the recommended approach for mobile applications.

  • Enhanced Security: Your app never handles user passwords directly
  • MFA Support: Multi-factor authentication works out of the box
  • SSO Enabled: Seamless single sign-on experience across apps
  • Federation Support: Social logins and enterprise identity providers
  • WebAuthn Ready: Support for passkeys and biometric authentication
