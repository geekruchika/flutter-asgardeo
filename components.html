Components Reference

Pre-built widgets to accelerate your authentication implementation

AsgardeoProvider

The root component that provides authentication state and methods to your entire widget tree.

Usage

AsgardeoProvider(
  config: AsgardeoConfig(
    baseUrl: 'https://api.asgardeo.io/t/yourorg',
    clientId: 'your-client-id',
    afterSignInUrl: 'myapp://callback',
    afterSignOutUrl: 'myapp://callback',
    scopes: ['openid', 'profile', 'email'],
  ),
  child: const MyApp(),
)

Props

Property Type Required Description
config AsgardeoConfig Yes Configuration object containing Asgardeo settings
child Widget Yes Your application's root widget
Best Practice: Place AsgardeoProvider at the root of your app, wrapping the MaterialApp or CupertinoApp widget. This ensures authentication state is available throughout your entire widget tree.

Control Components

Components that conditionally render content based on authentication state.

SignedIn

Renders its child only when the user is authenticated.

Usage

SignedIn(
  fallback: const Text('Please sign in'),
  child: Column(
    children: [
      const Text('Welcome back!'),
      const UserButton(),
    ],
  ),
)

Props

Property Type Required Description
child Widget Yes Content to show when user is signed in
fallback Widget? No Content to show when user is not signed in (defaults to empty)

Example with Fallback

SignedIn(
  fallback: Center(
    child: Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        const Icon(Icons.lock_outline, size: 48),
        const SizedBox(height: 16),
        const Text('Sign in to view your dashboard'),
        const SizedBox(height: 16),
        SignInButton(),
      ],
    ),
  ),
  child: const DashboardContent(),
)

SignedOut

Renders its child only when the user is not authenticated.

Usage

SignedOut(
  child: Column(
    children: [
      const Text('Welcome to our app'),
      SignInButton(),
    ],
  ),
)

Props

Property Type Required Description
child Widget Yes Content to show when user is signed out

Common Pattern

Scaffold(
  body: Center(
    child: Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        SignedIn(
          child: const Text('You are signed in!'),
        ),
        SignedOut(
          child: SignInButton(),
        ),
      ],
    ),
  ),
)

Action Components

Interactive widgets that trigger authentication actions.

SignInButton

A button that initiates the sign-in flow when pressed.

Usage

SignInButton(
  child: const Text('Sign in with Asgardeo'),
  onSuccess: (user) {
    print('User signed in: ${user.username}');
  },
  onError: (error) {
    print('Sign in error: $error');
  },
)

Props

Property Type Required Description
child Widget? No Custom button content (defaults to "Sign In")
onSuccess Function(User)? No Callback when sign-in succeeds
onError Function(Object)? No Callback when sign-in fails

Custom Styling

SignInButton(
  child: Container(
    padding: const EdgeInsets.symmetric(horizontal: 24, vertical: 12),
    decoration: BoxDecoration(
      gradient: const LinearGradient(
        colors: [Colors.blue, Colors.purple],
      ),
      borderRadius: BorderRadius.circular(8),
    ),
    child: const Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        Icon(Icons.login, color: Colors.white),
        SizedBox(width: 8),
        Text('Sign In', style: TextStyle(color: Colors.white)),
      ],
    ),
  ),
)

SignOutButton

A button that signs the user out when pressed.

Usage

SignOutButton(
  child: const Text('Sign Out'),
  onSuccess: () {
    print('User signed out');
  },
  onError: (error) {
    print('Sign out error: $error');
  },
)

Props

Property Type Required Description
child Widget? No Custom button content (defaults to "Sign Out")
onSuccess VoidCallback? No Callback when sign-out succeeds
onError Function(Object)? No Callback when sign-out fails

UserButton

A compact user avatar button with a dropdown menu for account actions.

Usage

AppBar(
  title: const Text('My App'),
  actions: [
    SignedIn(
      child: Padding(
        padding: const EdgeInsets.only(right: 8),
        child: UserButton(
          size: 36,
          onSignOut: () {
            Navigator.pushReplacementNamed(context, '/');
          },
        ),
      ),
    ),
  ],
)

Props

Property Type Default Description
size double 36 Size of the avatar button
onSignOut VoidCallback? null Callback after user signs out

AuthView

A prebuilt authentication view with sign-in UI, useful for presenting auth in a modal or bottom sheet.

Usage

showModalBottomSheet(
  context: context,
  builder: (context) => AuthView(
    title: 'Welcome Back',
    onSuccess: (user) {
      Navigator.pop(context);
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Welcome ${user.username}!')),
      );
    },
    onError: (error) {
      Navigator.pop(context);
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Sign in failed')),
      );
    },
  ),
);

Props

Property Type Default Description
title String 'Sign in' Title text displayed above the sign-in button
onSuccess Function(User)? null Callback when sign-in succeeds
onError Function(Object)? null Callback when sign-in fails

Organization Components

Components for managing multi-tenant applications with organization switching.

OrganizationSwitcher

A dropdown that allows users to switch between organizations they have access to.

Usage

class OrgSwitcherWidget extends StatelessWidget {
  const OrgSwitcherWidget({super.key});

  @override
  Widget build(BuildContext context) {
    final auth = AsgardeoProvider.of(context);

    return SignedIn(
      child: FutureBuilder<List<Organization>>(
        future: auth.getMyOrganizations(),
        builder: (context, snapshot) {
          if (snapshot.connectionState == ConnectionState.waiting) {
            return const CircularProgressIndicator();
          }
          
          if (snapshot.hasError) {
            return const Text('Failed to load organizations');
          }

          final orgs = snapshot.data ?? [];
          if (orgs.isEmpty) {
            return const SizedBox.shrink();
          }

          return OrganizationSwitcher(
            organizations: orgs,
            current: auth.currentOrganization,
            onSwitch: (org) async {
              await auth.switchOrganization(org);
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('Switched to ${org.name}')),
              );
            },
          );
        },
      ),
    );
  }
}

Props

Property Type Required Description
organizations List<Organization> Yes List of available organizations
current Organization? No Currently selected organization
onSwitch Function(Organization)? No Callback when organization is switched
How Organization Switching Works: When a user switches organizations, the SDK performs a token exchange using the organization_switch grant type. This updates the access token to include the new organization context without requiring re-authentication.

Component Best Practices

1. Use Control Components for Conditional Rendering

Instead of manually checking auth state, use SignedIn and SignedOut components:

// ✅ Good
SignedIn(
  child: const DashboardContent(),
  fallback: const LoginPrompt(),
)

// ❌ Avoid
final auth = AsgardeoProvider.of(context);
auth.isSignedIn ? const DashboardContent() : const LoginPrompt()

2. Handle Callbacks Appropriately

Use callbacks for navigation, analytics, or showing notifications:

SignInButton(
  onSuccess: (user) {
    // Track sign-in event
    analytics.logEvent('user_signed_in');
    
    // Navigate to dashboard
    Navigator.pushReplacementNamed(context, '/dashboard');
  },
  onError: (error) {
    // Show error message
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Sign in failed: $error')),
    );
  },
)

3. Customize Components to Match Your Brand

All action components accept custom child widgets for full styling control.
