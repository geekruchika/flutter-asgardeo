API Reference

Complete reference for all SDK classes and methods

AsgardeoAuth

The main authentication client that manages user sessions, tokens, and authentication state. Access it via AsgardeoProvider.of(context).

Getting the Instance

final auth = AsgardeoProvider.of(context);

Properties

isInitialized

Returns whether the SDK has been initialized.

bool get isInitialized

isLoading

Returns whether an authentication operation is in progress.

bool get isLoading

Example:

final auth = AsgardeoProvider.of(context);
if (auth.isLoading) {
  return const CircularProgressIndicator();
}

isSignedIn

Returns whether the user is currently authenticated.

bool get isSignedIn

Example:

final auth = AsgardeoProvider.of(context);
if (auth.isSignedIn) {
  return const DashboardPage();
} else {
  return const LoginPage();
}

currentOrganization

Returns the currently active organization (if any).

Organization? get currentOrganization

Methods

signIn()

Initiates the sign-in flow using the system browser (ASWebAuthenticationSession on iOS, Custom Tabs on Android).

Signature

Future<User?> signIn([Map<String, dynamic>? options])

Parameters

Parameter Type Description
options Map<String, dynamic>? Optional configuration for the sign-in request (e.g., custom scopes)

Returns

Future<User?> - The authenticated user or null

Example

final auth = AsgardeoProvider.of(context);
try {
  final user = await auth.signIn();
  if (user != null) {
    print('Signed in as: ${user.username}');
  }
} catch (e) {
  print('Sign in failed: $e');
}

With Custom Scopes

final user = await auth.signIn({
  'scopes': ['openid', 'profile', 'email', 'phone'],
});

signOut()

Signs the user out and clears the session.

Signature

Future<void> signOut()

Returns

Future<void>

Example

final auth = AsgardeoProvider.of(context);
try {
  await auth.signOut();
  Navigator.pushReplacementNamed(context, '/');
} catch (e) {
  print('Sign out failed: $e');
}

getAccessToken()

Retrieves the current access token. Automatically refreshes the token if it's expired.

Signature

Future<String> getAccessToken()

Returns

Future<String> - The access token

Example

final auth = AsgardeoProvider.of(context);
final token = await auth.getAccessToken();

// Use token for API calls
final response = await http.get(
  Uri.parse('https://api.example.com/data'),
  headers: {
    'Authorization': 'Bearer $token',
  },
);
Best Practice: Always call getAccessToken() before making API requests to ensure you have a valid, non-expired token.

getDecodedIdToken()

Returns the decoded ID token containing user claims.

Signature

Future<Map<String, dynamic>> getDecodedIdToken()

Returns

Future<Map<String, dynamic>> - The decoded ID token payload

Example

final auth = AsgardeoProvider.of(context);
final idToken = await auth.getDecodedIdToken();

print('User ID: ${idToken['sub']}');
print('Email: ${idToken['email']}');
print('Name: ${idToken['name']}');

Common Claims

Claim Description
sub Subject identifier (user ID)
email User's email address
name User's full name
preferred_username User's username
given_name User's first name
family_name User's last name

getMyOrganizations()

Retrieves the list of organizations the user belongs to.

Signature

Future<List<Organization>> getMyOrganizations()

Returns

Future<List<Organization>> - List of organizations

Example

final auth = AsgardeoProvider.of(context);

  print('Organization: ${org.name} (${org.id})');
}

switchOrganization()

Switches the current organization context using token exchange.

Signature

Future<void> switchOrganization(Organization org)

Parameters

Parameter Type Description
org Organization The organization to switch to

Returns

Future<void>

Example

final auth = AsgardeoProvider.of(context);
final orgs = await auth.getMyOrganizations();

if (orgs.isNotEmpty) {
  await auth.switchOrganization(orgs.first);
  print('Switched to: ${auth.currentOrganization?.name}');
}
How it works: Organization switching uses the organization_switch grant type to exchange the current access token for a new one with the selected organization's context. This doesn't require re-authentication.

handleRedirect()

Processes the redirect URI after authentication. Call this in your deep link handler.

Signature

Future<void> handleRedirect(Uri redirectUri)

Parameters

Parameter Type Description
redirectUri Uri The redirect URI received from the deep link

Example

StreamSubscription? _sub;

@override
void initState() {
  super.initState();
  _sub = uriLinkStream.listen((Uri? uri) async {
    if (uri != null && mounted) {
      await AsgardeoProvider.of(context).handleRedirect(uri);
    }
  });
}

Models

AsgardeoConfig

Configuration object for initializing the SDK.

Properties

Property Type Required Description
baseUrl String Yes Asgardeo organization base URL
clientId String Yes Application client ID from Asgardeo
afterSignInUrl String Yes Redirect URL after sign-in
afterSignOutUrl String Yes Redirect URL after sign-out
scopes List<String> No OAuth scopes (defaults to ['openid', 'profile', 'email'])

Example

const config = AsgardeoConfig(
  baseUrl: 'https://api.asgardeo.io/t/myorg',
  clientId: 'abc123def456',
  afterSignInUrl: 'myapp://callback',
  afterSignOutUrl: 'myapp://callback',
  scopes: ['openid', 'profile', 'email', 'phone'],
);

Error Handling

All async methods may throw exceptions. Always wrap them in try-catch blocks:

try {
  await auth.signIn();
} catch (e) {
  if (e is TimeoutException) {
    // Handle timeout
  } else if (e is HttpException) {
    // Handle network error
  } else {
    // Handle other errors
  }
}
